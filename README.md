# 🐉 What is DragonHub?

**DragonHub** is an all-in-one desktop workspace created to bring essential tools and workflows together inside a single modern application.

Instead of constantly switching between different applications for coding, managing files, working with media, taking notes, handling downloads, and completing everyday tasks, DragonHub aims to provide a unified environment where everything is available from one place.

> **One application. One workspace. Endless possibilities.**

DragonHub is designed for developers, creators, students, power users, and anyone who wants a cleaner and more centralized digital workspace.

# DragonHub v1.3.0 — by AHMADDRAGON (https://t.me/ahmaddragon)

**دراغون هب** — مركز تحكم مكتبي مشفّر يعمل محلياً (Windows 10/11 x64):
ملاحظات، مشاريع وأفكار، مهام (Kanban)، مدير ملفات بلوحتين، محرر أكواد (Monaco)،
مدير تحميل متعدد الاتصالات + تحميل وسائط (yt-dlp)، مركز ضغط (ZIP/7z/TAR/GZIP/XZ مع تشفير AES-256)،
استوديو صور (sharp)، استوديو فيديو وصوت (FFmpeg)، خزنة مشفّرة (AES-256-GCM)،
اختصارات لوحة مفاتيح، إعدادات شاملة، عربي (RTL) وإنجليزي، داكن/فاتح/نظام.

## البناء على Windows (Node.js 20+)

```
npm install
npm run typecheck   # فحص الأخطاء (بدون بناء)
npm run build       # بناء الواجهة + Electron
npm run dist        # -> release/1.3.0/*.exe (مثبّت + نسخة محمولة)
npm run dev         # وضع التطوير
```

إدارة الإصدارات: `npm run version:patch|minor|major`.
ملف الأيقونة `build/icon.ico` موجود وجاهز للبناء.

## البناء والنشر عبر GitHub Actions

يوجد Workflow في `.github/workflows/build-windows.yml`. عند الدفع إلى `main`
يتم البناء ورفع ملفات Windows كـ Artifact مؤقت. لإنشاء Release دائم يمكن للجميع
تنزيله، أنشئ Tag يبدأ بحرف `v` وادفعه إلى GitHub:

```bash
git tag v1.3.0
git push origin v1.3.0
```

سيبني GitHub Actions نسخة NSIS ونسخة Portable ويرفقهما تلقائياً بصفحة Releases.

> ملاحظة: مجلد `node_modules` غير مضمّن في الأرشيف. أول `npm install` يحتاج إنترنت
> (تحميل كبير لمرة واحدة). بعد ذلك البناء يعمل محلياً بالكامل.

## أين بيانات المستخدم؟ (User data locations)

| البيانات | الموقع |
|---|---|
| الإعدادات | `%APPDATA%\DragonHub\dragonhub-settings.json` |
| الملاحظات/المشاريع/المهام/التنزيلات | `%APPDATA%\DragonHub\dragonhub-data.json` |
| الخزنة (مشفرة) | `%APPDATA%\DragonHub\vault\vault.meta.json` + `vault.bin` |
| نسخ أمان الخزنة | `vault.bin.bak` / `.pre-import.bak` (تُنشأ تلقائياً عند تغيير كلمة المرور أو الاستيراد) |
| التنزيلات الافتراضية | `~\Downloads\DragonHub` (قابل للتغيير من الإعدادات) |
| الشبكة (العدادات/السقف اليومي/الخطط/السجل) | `%APPDATA%\DragonHub\dragonhub-data.json` مفاتيح `net.*` (محلية فقط، بلا سحابة) |

فتح مجلد البيانات مباشرة: الإعدادات ← البيانات ← «فتح مجلد البيانات».

## الأمان (مختصر)

- عزل السياق (contextIsolation) + renderer في sandbox، ولا `nodeIntegration`.
- الإذن الوحيد المسموح به هو إشعارات سطح المكتب (تذكيرات المهام).
- التحقق من المسارات في العملية الرئيسية + فحص ZipSlip قبل الاستخراج.
- الخزنة: PBKDF2-SHA512 (600k تكرار) + AES-256-GCM، المفتاح في الذاكرة فقط،
  وكلمة المرور الرئيسية **لا يمكن استعادتها** إن نُسيت — صدّر نسخة `.dhvault` مشفرة واحتفظ بها.
- سلة المحذوفات الأصلية عبر `shell.trashItem`.
- التفاصيل الكاملة: `SECURITY_NOTES.md`.

## الجديد في 1.2.0

- حماية الاستخراج من ZipSlip والقنابل المضغوطة، وعدم الكتابة فوق الملفات silently.
- تغيير كلمة مرور الخزنة آمن ضد التعطل + نسخ احتياطية تلقائية.
- إصلاحات: فتح الملفات الضخمة، المهام المتكررة، تكرار الملاحظات، استعادة تبويبات المحرر،
  الحفظ عند الإغلاق، الاختصارات أثناء الكتابة.
- أوامر سريعة جديدة في لوحة الأوامر (Ctrl+K)، ودورة سمة ثلاثية (داكن/فاتح/نظام).
- التفاصيل: `CHANGELOG.md`. الصيغ المدعومة والقيود: `SUPPORTED_FORMATS.md`.
  البنية: `ARCHITECTURE.md`. تقرير التحقق: `VERIFICATION_REPORT.md`.

## الشبكة والاستهلاك (جديد في 1.3.0)

- صفحة «الشبكة والاستهلاك»: سرعة لحظية (تنزيل/رفع) + استهلاك اليوم (تنزيل/رفع/إجمالي)،
  تُقرأ من عدّادات واجهة النظام (`netstat -e` مع احتياطي PowerShell) بشكل سلبي تماماً — التطبيق نفسه لا يستخدم إنترنت لهذه القراءة ولا يحتاج صلاحيات.
- سقف يومي (GB) اختياري مع حظر تلقائي لإنترنت الجهاز كاملاً عند التجاوز (قواعد Windows Firewall،
  تتطلب التشغيل كمسؤول — UAC)، واستعادة تلقائية عند منتصف الليل (عند تفعيل الخيار) مع حصة متجددة، وخيار استعادة عند الخروج،
  وتنظيف عند بدء التشغيل حتى لا يبقى الجهاز محظوراً بعد أي تعطل (fail-open).
- خطط البيانات: اسم + حصة + دورة (يومية/أسبوعية/شهرية/مخصصة N أيام) + تاريخ بداية → مخصص يومي تلقائي،
  وشريط تقدم الاستخدام مقابل الحصة، وجدول سجل 14 يوماً؛ التصفير عند منتصف الليل المحلي.
- حدود صريحة: إجماليات على مستوى النظام (لا تفصيل لكل تطبيق بدون driver/ETW)، العدّادات تُصفَّر عند إعادة التشغيل
  (يُعالَج بإعادة التأسيس rebasing)، حظر الجدار الناري يحتاج مسؤولاً، ولا مزامنة سحابية/هاتف.
- التفاصيل الكاملة: `NETWORK.md`.

## القيود المعروفة (باختصار)

- لا يوجد محدّث تلقائي — الإصدارات تُعلن عبر قناة تيليجرام.
- تحميل الوسائط (yt-dlp) يعتمد على الموقع المصدر وقد يفشل مع المحتوى المحمي.
- التراجع (Undo) لعمليات الملفات غير متوفر بعد — الحذف يستخدم سلة المحذوفات افتراضياً.
- التفاصيل: `SUPPORTED_FORMATS.md`.
